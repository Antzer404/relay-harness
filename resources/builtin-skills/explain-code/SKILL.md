# 代码讲解

面向刚接手代码的读者，把「它是干什么的、怎么跑起来、改哪里」讲清楚。

## 步骤

1. 读入口与导出：文件顶部、导出列表，并用 Grep 找调用方，确认它不是死代码。
2. 顺着主流程走一遍，记录数据从哪来、经过哪些函数、落到哪里。
3. 找出隐性约定：配置默认值、状态机、重试与超时、副作用（写文件、发请求、改全局状态）。
4. 标注易错点：边界条件、并发、平台差异、历史包袱。

## 输出结构

- **一句话定位**：这个模块解决什么问题。
- **结构**：关键文件与函数各自的职责（列表，带 `file:line`）。
- **主流程**：按调用顺序编号，每一步说明输入与输出。
- **数据与状态**：存在哪里、谁修改、生命周期多长。
- **对外接口**：参数、返回值、错误语义。
- **坑与约定**：不明显的假设、已知问题。
- **建议阅读顺序**：3–5 个文件，从浅到深。

## 约束

- 结论必须来自实际阅读；不确定的地方明确写「未验证」。
- 不要贴大段源码，引用关键行号即可。
